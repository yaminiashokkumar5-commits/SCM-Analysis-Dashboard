# Inventory and Supply Chain Management Analysis | Power BI

## Project Overview
An interactive Power BI dashboard developed to analyze inventory performance, warehouse utilization, transportation costs, sales trends and order fulfillment.

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization

## Key Features
- Warehouse Utilization KPI
- Days Sales of Inventory
- Inventory Turnover Ratio
- Transportation Cost by Region and Category
- Units Sold by Year
- Average Lead Time by Category
- Backorder Analysis by Order Status
- Inventory Level by Category and Region
- Interactive Region and Category filters
